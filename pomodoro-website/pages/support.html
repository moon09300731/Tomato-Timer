常见问题

如果您遇到问题，请先查看以下解答

番茄钟应用是免费的吗？

是的，番茄钟应用完全免费。您可以免费下载和使用所有功能。如果您喜欢这个应用，可以通过打赏支持我们的开发工作。

支持哪些操作系统？

目前番茄钟应用仅支持 macOS 系统。最低系统要求为 macOS 11.0。我们正在考虑未来支持 Windows 和 Linux 版本。

如何更新应用到最新版本？

您可以在我们的网站下载页面获取最新版本。建议先卸载旧版本，然后安装新版本。未来版本将添加自动更新功能。

数据会保存在哪里？

所有数据都保存在您的本地设备上。我们不会收集或上传您的任何使用数据。您可以随时导出统计数据。

如何导出统计数据？

在统计仪表板页面，您可以找到"导出数据"按钮。支持导出为 CSV 和 JSON 格式，方便您在其他应用中分析数据。
